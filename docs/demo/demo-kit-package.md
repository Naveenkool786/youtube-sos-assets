## 📊 How to Track Feedback

### Simple Google Sheet

Create a sheet with these columns:

| Name | Company | Role | Date Sent | Opened Demo? | Submitted Feedback? | Overall Score (1-10) | Would Use? | Followup Needed |
|---|---|---|---|---|---|---|---|---|
| | | | | | | | | |

### Feedback Form Submissions

The feedback form (link #4) sends completed responses to your email as `mailto:` messages. Create a Gmail filter:
- From: *
- Subject contains: "Weftly feedback"
- Apply label: "Weftly Pilot Feedback"
- Star it

Then weekly:
1. Read every response
2. Add to the tracking sheet
3. Reply to EVERY person who submitted (thank-you, template 6)

### Qualitative themes to look for

After 10+ responses, group feedback into themes:

- **Confusion themes** → What people got stuck on → Prototype v2 priority
- **"Must-have" features** → What everyone mentioned → Pilot MVP scope
- **Would-pay signals** → Price mentions + Yes-I'd-use answers → Pilot customer prospects
- **Introductions** → Who else to talk to → Weekly follow-up list

## 🎯 Success Metrics for Your Demo Week

**Minimum viable success** (you learn something):
- 5 people clicked the demo
- 3 people submitted the feedback form
- 1 real conversation booked

**Good week** (you're on track):
- 10 people clicked the demo
- 7 submitted feedback
- 3 real conversations booked
- 1-2 pilot customer leads identified

**Great week** (unusual, don't expect):
- 20+ demo opens
- 15+ feedback submissions
- 5+ real conversations booked
- 2-3 pilot customers advancing to detailed talks

**Red flag** (something's broken):
- 10+ people opened demo, 0 feedback → Form is broken OR demo is boring
- 5+ "I don't get it" responses → Website messaging is unclear
- 0 "yes I'd pay" responses → Product direction is off

## 🎓 One Final Reminder — The Mom Test

When sharing with potential customers, remember:

1. **Talk about their life, not your idea** — "How do you handle quality issues today?" NOT "Would you use my app?"
2. **Ask about the past, not the future** — "Tell me about the last defect you had" NOT "Would you want to track defects?"
3. **Shut up and listen** — Let silence pull out the real answer

See the demo guide artifact for the 6-question Mom Test cheat sheet. It's embedded in the walkthrough.
